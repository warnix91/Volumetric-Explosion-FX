# Volumetric Explosion FX

**VEFX · KSP 1.12.5 · Windows · MIT**

Volumetric fireballs, smoke, visual debris, ground fires and water impacts.
Effects respond to the vessel’s resources, motion and environment.
Visual effects only — no changes to gameplay or physics.

## Installation

1. Close KSP.
2. Extract the release ZIP and copy `VolumetricExplosionFX` into `GameData`.
3. Launch KSP. The flame toolbar button opens the settings.

No other mods are required. When updating, keep your
`VolumetricExplosionFX/PluginData/settings.cfg` to retain your settings.
To uninstall, remove `GameData/VolumetricExplosionFX`.

## Settings

**Ultra is the default quality.** Select High, Medium or Low if you need better
performance. Existing saved settings take precedence over the defaults.

Adjust intensity and effect limits, or use the in-flight preview to see your
changes. The interface follows the language selected in KSP.

## Compatibility

This release is validated on **Windows with KSP 1.12.5**. macOS and Linux are
not validated. Other explosion mods may produce overlapping effects.
