# Volumetric Explosion FX

**VEFX** adds fireballs, smoke, visual wreckage, ground fires and water-impact effects
to Kerbal Space Program 1.12.5. Effects respond to the destroyed vessel's resources,
motion and environment.

The mod changes visuals only. It adds no damage, forces, physical debris, resource
consumption or persistent save data. Other mods are optional.

## Status

Version 0.9.0 is in preparation for a Windows beta. In-game validation is still pending.
macOS support is postponed; the mod is not automatically disabled on Mac.
Linux support is unverified. See [compatibility](docs/COMPATIBILITY.md).

## Installation

Use a built package, with KSP closed.

1. Back up your previous VEFX settings.
2. If upgrading from ProjectDestructionFX, preserve PluginData/settings.cfg and remove
   GameData/ProjectDestructionFX. The two folders must not be installed together.
3. Copy GameData/VolumetricExplosionFX from the package into KSP's GameData.
4. Restore your profile to the new folder's PluginData/settings.cfg, if needed.

The flame toolbar button opens settings in flight and at the Space Center.
Remove GameData/VolumetricExplosionFX to uninstall.

The source checkout is not an installable package. See the [build guide](docs/BUILD.md).
