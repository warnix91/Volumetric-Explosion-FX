# Volumetric Explosion FX — v1.0

Visual explosion effects for KSP 1.12.5, by Warnix. Gameplay and physics are unchanged.

## Installation

Close KSP, then copy `VolumetricExplosionFX` into `GameData`.
To uninstall, remove `GameData/VolumetricExplosionFX`.

## Settings

Use the flame toolbar button in flight or at the Space Center.
Settings are saved to `PluginData/settings.cfg`.
