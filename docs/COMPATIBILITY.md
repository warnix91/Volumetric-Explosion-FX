# Compatibility

Game version: KSP 1.12.5.

| Platform | Status |
|---|---|
| Windows | First beta target. KSP validation remains pending. |
| macOS | Support postponed. No automatic platform disable. |
| Linux | Unverified. |

No mandatory dependencies on GroundBlastFx, Waterfall, RealFuels or ModuleManager.
VEFX does not change another mod's configuration. Explosion or impact mods may overlap
visually; rendering mods may affect depth, transparency, exposure or lighting.
Compatibility with a complete mod stack requires an in-game check.

Shader bundles use Unity 2019.4.18f1 and are built separately for each target.
Missing or unsupported volumetric shaders retain the particle fallback.
